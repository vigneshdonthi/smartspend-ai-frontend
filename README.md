# 💰 SmartSpend AI - Frontend

SmartSpend AI is a modern AI-powered personal finance management application that helps users track expenses, manage budgets, visualize spending, and generate professional financial reports.

Built with **React**, **Vite**, **Tailwind CSS**, and **Shadcn UI**, the application provides a fast, responsive, and intuitive user experience.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/smartspend-ai-frontend.git
```

Go to the project directory

```bash
cd smartspend-ai-frontend
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
VITE_API_URL=http://localhost:8000/api
```

Start the development server

```bash
npm run dev
```
